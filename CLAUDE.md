The checkout's `.mcp.json` declares the `gaie` stdio server. Open Claude Code
from this checkout's root and review the project-scoped server before enabling
it. Use `tools/list` to discover the entry points. Each tool takes a `request`
object using the corresponding `python3 -m engineering_os.intelligence`
schema. Use project `gaie` with the checked-in server configuration. The
terminal CLI remains available for operator-selected local paths. See
`skills/nextgen-intelligence/SKILL.md`.

For a direct request to build a new project or upgrade an existing one, first
check `mcp__gaie__gaie_master_status`. With an approved source enabled, send the
original sentence to `mcp__gaie__gaie_master_route`. Follow the routed MASTER
skill and call `mcp__gaie__gaie_master_execute` with the same sentence and the
structured workflow. Use preview when required inputs or workspace authority
are missing. A blocked, ambiguous, negated or unrelated route supplies no write
authority. Report an approval gate and continue within the tools and scopes that
are already enabled if the MASTER tools are unavailable.

For an operator-controlled local server, start
`python3 -m engineering_os.claude_bridge --project <project>` from the checkout
root. Optional startup arguments enable private or file-bound operations:

- `--memory-dir <absolute-private-dir>` enables project memory search, graph and
  recording. Use the same private state directory as Codex for that project.
- `--artifact-root <absolute-existing-dir>` enables factory artifact validation
  and, with memory enabled, indexes visible Python paths in that directory.
- `--destination <absolute-new-dir>` enables the verified SQLite factory for
  one destination within a private parent outside Git.
- `--checkpoint-dir` and `--receipt-dir` bind separate private directories for
  backup IDs and solution verification receipts. The client supplies IDs.
- `--browser-cache` binds the reviewed Playwright browser cache for the fixed
  localhost QA fixture.
- `--master-approval`, `--master-approval-sha256` and `--master-source-root`
  bind an owner-reviewed, exact merged source. `--master-workspace` binds the
  local upgrade checkout. The default configuration lists MASTER status while
  waiting for approved source. See `docs/specs/nextgen-intelligence/master-mcp.md`.

Keep private paths in local host configuration. The server uses bounded stdio
messages and requires no provider credentials. The subprocess tests validate MCP
initialization, tool discovery, calls and project isolation. Verify the server's
startup and tool list separately in your Claude Code session before claiming
host activation.
