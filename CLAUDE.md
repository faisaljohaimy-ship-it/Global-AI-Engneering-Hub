For an operator-controlled local server, start
`python3 -m engineering_os.claude_bridge --project <project>` from the checkout
root. Optional startup arguments enable private or file-bound operations:

- `--memory-dir <absolute-private-dir>` enables project memory search, graph and
  recording. Use the same private state directory as Codex for that project.
- `--artifact-root <absolute-existing-dir>` enables factory artifact validation
  and, with memory enabled, indexes visible Python paths in that directory.
- `--destination <absolute-new-dir>` enables the verified SQLite factory for
  one destination within a private parent outside Git.

Keep private paths in local host configuration. The server uses bounded stdio
messages and requires no provider credentials. The subprocess tests validate MCP
initialization, tool discovery, calls and project isolation. Verify the server's
startup and tool list separately in your Claude Code session before claiming
host activation.
