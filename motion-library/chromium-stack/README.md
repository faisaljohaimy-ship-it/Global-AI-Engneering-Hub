# Chromium motion stack — opt-in candidate
This manifest is a discovery/install candidate, not an approved or tested runtime. All dependency versions are deliberately unresolved until review. Before installation, resolve exact compatible versions, review licenses (especially Remotion, Rive and GSAP commercial terms), advisories and transitive dependencies, replace latest with exact versions, create and review a lockfile. Do not incur charges. Use an isolated workspace without credentials.
After approval: npm ci; npx playwright install chromium; npm run smoke.
Browser native capabilities: CSS animations, WAAPI, WebGL/WebGPU, GLSL/WGSL; feature-detect and provide fallback. WebGPU and GPU acceleration are device dependent. Package resolution is not proof of rendering.
Use GSAP/Motion for UI, Three/R3F for spatial scenes, Theatre for timelines, Remotion for video, Rive/Lottie for assets. Test each independently with licensed sample assets. Lighthouse and axe for quality; Puppeteer and Playwright for browser automation. MCP servers are opt-in, local only, least privilege, no authenticated browser profiles or untrusted instructions. Configure agents with pinned package commands only after review.
Acceptance: per-library render test, RTL, reduced motion, mobile Safari/WebKit fallback, performance budget, dependency audit, reproducible lockfile, no secrets, no production deployment. Record evidence before promoting any entry to operational status.
