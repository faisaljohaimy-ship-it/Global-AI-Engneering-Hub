## Acceptance

1. Each application has a private repository, a proven source ref/path, a preserved
   history map and byte-identical source/media inventory before its integration moves.
2. A versioned, selectively installed SDK verifies its local capability copies without
   contacting the public hub. Both agent skill locations use the same pinned files.
3. Target validation rejects another repository, team, project, root or commit.
   Release evidence must bind all mandatory checks and smoke tests to that exact SHA;
   unknown settings and missing rollback evidence block release.
4. Discovery is read-only. MCP exposes catalog/verification only. Chromium, Remotion,
   WebGPU and AI tools retain honest reviewed/candidate/runtime status. Discovery
   never installs software, authenticates a service or starts a paid operation.
5. Existing domains, data, credentials, production artifacts and rollback candidates
   are preserved. No duplicate Vercel projects, forced pushes or deletion of Wow-bus.
6. Private project inventories and migration evidence stay outside this public hub.
