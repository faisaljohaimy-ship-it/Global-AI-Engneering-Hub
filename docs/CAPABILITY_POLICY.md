# Capability lifecycle
Discovered -> reviewed -> approved -> installed -> runtime verified. A catalog reference is not installation or approval. Require upstream identity, pinned immutable version, license including commercial use, security review, budget and compatible sandbox test. Never auto-execute discovery candidates. Keep provider credentials outside GitHub source. Do not copy client code or restricted media into the public hub. Store runtime evidence per project, without private inputs. No paid services, no GPU jobs without a verified free allowance. For agent-specific skill discovery, explicitly copy only reviewed SKILL.md directories into the supported skill path in an isolated project branch. Verify both agents separately.
